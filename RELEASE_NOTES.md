# v0.2.0 — Overlay sperimentale Windows

Prima distribuzione portatile con EXE Windows x64, configurazione grafica della minimappa e guida in italiano.

- Nuova icona forziere fornita dall'utente, senza sfondo circolare o linee, ricavata dall'originale ad alta risoluzione.
- Zoom progressivo in base ai punti vicini; coordinate delle icone non spostate artificialmente.
- Pannello riorganizzato con righe distinte per zoom, dati e configurazione; overlay più grande.
- Corrette risposte asincrone obsolete che potevano cancellare una posizione nuova.
- I conflitti di una scorciatoia non disabilitano più tutte le altre.
- Ripiego del monitor dell'overlay e prevenzione di più istanze nella stessa cartella.
- Vecchia AI per rilevare casse rimossa; XFeat ONNX disponibile soltanto come confronto offline. Il confronto disponibile non dimostra miglioramenti: il matching live resta SIFT.

I punti mostrano possibili spawn, non lo stato dei forzieri. Nessuna quota o posizione 3D. Test sintetici, avvio EXE e prove UI descritti nel report allegato; nessuna promessa di precisione generale in partita o compatibilità anti-cheat. La build è priva di firma digitale.
